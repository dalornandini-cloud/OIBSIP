## Task 1: Responsive Landing Page

A visually polished, static landing page built using only HTML and CSS.

**Features**
- Sticky navigation bar with multiple navigation links
- Hero section with headline, subheadline and call-to-action button
- Multiple content sections
- Footer with contact and social links
- Consistent colour palette and clean typography
- Fully responsive layout using Flexbox and CSS Grid

**Screenshots:** see the [`screenshots`](./Task-1-Landing-Page/screenshots) folder.

## Task 3: Temperature Converter

An interactive web tool that converts temperatures between Celsius, Fahrenheit and Kelvin.

**Features**
- Numeric input with real-time validation and clear error messages
- Unit selector (Celsius / Fahrenheit / Kelvin)
- Convert button showing all three units at the same time
- Result display with correct unit labels
- Absolute zero handling (rejects values below -273.15°C, -459.67°F or 0 K)
- Clean, centred and responsive UI

**Screenshots:** see the [`screenshots`](./Task-3-TemperatureConverter/screenshots) folder (input, error state, working output).
